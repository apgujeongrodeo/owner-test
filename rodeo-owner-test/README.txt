사장님 동네 — 나는 어떤 사장님일까?

대상: 로데오 공인중개사무소 김태욱님을 만날 예비·현재 자영업 고객.
목적: 고객이 일상의 상황에 선택하며 재미있게 자기 운영 스타일을 발견하는 입구.
콘텐츠 제작 취향 테스트가 아닙니다.

사용 방법
압축을 푼 뒤 index.html, style.css, app.js가 바로 들어 있는 rodeo-owner-test 폴더를 Netlify의 수동 배포 영역에 올립니다.
Vercel에서는 정적 사이트로 배포하면 됩니다. 빌드 명령이나 설치가 필요 없습니다.
index.html을 직접 열어도 사용할 수 있습니다.

문항/점수
- 총 10문항, 매 문항 선택지 2개
- 1~5번: 현장 조율 vs 운영 기준
- 6~10번: 작은 실험 vs 사전 설계
- 각 다섯 문항 중 3개 이상 선택한 쪽을 조합해 총 4유형
- 3:2이면 혼합형에 가깝다는 설명 포함

포함 기능
- 네 가지 동물 사장님 캐릭터
- 이전 질문/이어하기/답변 수정
- 결과별 공감 설명, 스트레스 상황, 현실 팁, 상가 확인 체크리스트
- 결과 링크 복사 및 PNG 결과 카드 저장
- 상가 상담 전 메모 작성/복사: 실제 문의를 전송하는 기능은 아닙니다.
- 개인정보 입력/서버 전송/방문자 추적/결제 없음
- 응답과 메모는 이 브라우저 안에만 저장. 초기화 버튼 제공
- 외부 이미지/폰트/CDN 없이 동작

향후 연결
app.js의 CONFIG.consultationUrl에 실제 상담·랜딩페이지 HTTPS 주소를 입력하면 결과 아래에 연결 버튼이 표시됩니다.
현재 주소를 제공받지 않았으므로 비어 있습니다. 전화번호·예약 URL·가격 등은 임의로 넣지 않았습니다.
결제/유료 분석/커뮤니티는 구현하지 않았습니다.

파일 편집
app.js의 questions: 질문과 두 선택지
app.js의 types: 유형명, 설명, 팁, 체크리스트
style.css의 :root: 색상

검사 결과가 특정 매물 추천, 법률·재무 자문, 정신건강 평가를 대체하지 않습니다.
